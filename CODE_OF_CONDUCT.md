# Code of conduct

Be kind and be useful. This project is small and run by one person in their spare time, so the rules are short.

- Treat everyone with respect, whatever their background or experience. Disagree with ideas, not with people.
- No harassment, personal attacks, discrimination or unwelcome advances, in issues, pull requests, discussions or anywhere the project
  is represented.
- Assume good faith, say what you need clearly, and accept that a no from the maintainer on a feature is not personal.
- Do not publish other people's private information.

Comments and contributions that break these rules can be edited, hidden or removed, and repeat offenders can be blocked. To report a
problem, write to info@cristobaltormo.com; reports are kept private.
