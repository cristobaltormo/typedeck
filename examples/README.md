# Example macro packs

Files you can import from the editor (Gallery, or the layer panel, then **Import macros**). Each one is a small pack of macros for
a layer; the editor shows what an imported file contains before adding anything.

| File | What it shows |
|---|---|
| `developer.json` | Toggle an editor and a terminal, type git commands, a pomodoro timer, today's date |
| `meetings.json` | A sequence that opens Zoom and shows a popup, mute and camera shortcuts |
| `conditions.json` | Conditions: a launcher that depends on the system, a night mode by time of day, open the link in the clipboard, go live only if OBS is not streaming |
| `typing-history.json` | A key that switches the optional typing history on and off |

Keys are named by their USB usage in hex (`3A` is F1, `47` is Scroll Lock). They are only suggestions: move them to whichever key you
like once imported. The format is the same as the one the editor exports, so a layer you build and export can be shared the same way.
